# circle · 圆形排版工具

单文件 HTML 网页应用，零依赖。画布 + 基础圆形组件（4/6/10mm 预设 + 自定义），磁吸贴近、防重叠、不同尺寸不同颜色。

**在线使用（GitHub Pages）：** https://xiaoxilong.github.io/circle/

## 文件说明

- `index.html` —— 应用本体（手机/电脑均可打开）
- `circle-v11.html` —— 同 index.html 的副本（用于微信传文件）
- `probe.html` —— 环境诊断小工具（检测浏览器是否执行脚本）

## 本地运行

任意静态服务器即可，例如：

```bash
python -m http.server 8000
# 打开 http://localhost:8000/
```
